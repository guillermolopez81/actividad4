## Instalación en Windows

1. Instala XAMPP con PHP 8.2 de 64 bits y copia el proyecto en `C:\xampp\htdocs\CRM`.
2. Abre **XAMPP Control Panel** e inicia **Apache** y **MySQL**.
3. Abre [phpMyAdmin](http://localhost/phpmyadmin/), entra en **Importar** y selecciona [databases/CRM.sql](databases/CRM.sql). El archivo crea la base `CRM` con datos de demostración. Úsalo para una instalación nueva.
4. Abre el [CRM](http://localhost/CRM/public/) e inicia sesión con la cuenta de demostración.
